# Segurança e privacidade

A versão pública não contém:

- Tokens
- Credenciais
- Arquivos `.env`
- Bancos de dados
- Memórias locais
- Áudios pessoais
- Modelos treinados
- Servidor real
- Código completo da aplicação

O objetivo é apresentar o projeto de forma profissional sem expor sua implementação principal.
